# Security policy

## Supported version

Security fixes are targeted at the latest published RTSS Game Bar release.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting when it is enabled for the repository. Do not publish credentials, signing keys, private certificates, or exploit details in a public issue.

For normal bugs that do not expose sensitive information, use the repository issue tracker and include the RTSS Game Bar version, Windows version, Xbox Game Bar version, RTSS version, reproduction steps, and relevant logs.

## Signing key policy

The public `RTSSGameBar-Signing.cer` may be distributed with sideload releases.
