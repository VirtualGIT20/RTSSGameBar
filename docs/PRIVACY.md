# Privacy

RTSS Game Bar does not collect, transmit, sell, or share personal data.

The application has no telemetry, analytics, advertising SDK, account system, or network backend. Communication is local between the Xbox Game Bar widget, the packaged helper, the RTSS integration plugin, and RTSS itself.

Diagnostic logs are stored locally. The helper log is written under the current user's local application data directory and is bounded by simple rotation. The RTSS client plugin may write its local diagnostic log to the Windows temporary directory.

Users can delete these logs at any time. No log is uploaded automatically.
